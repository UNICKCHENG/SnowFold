# SnowFold 移动端布局（iPhone / iPad / 安卓手机与平板）

视觉语言（颜色、字体、卡片、圆角、图标）以桌面端为准，见 [design.md](design.md)。本文件只定**移动端的布局与交互**：桌面端是宽屏多列，手机是窄屏单列，结构按优秀 iOS 产品重新组织。iPhone 与安卓结构相同；安卓只把系统层面的行为换成原生（返回手势、edge-to-edge、SAF 文件选择、TalkBack、48dp 触控区）。

验收宽度：iPhone 375pt / 390pt，安卓 360dp；iPad 与安卓平板见第 8 节。所有页面必须在最长样例（资产名「招商银行朝朝宝（活期理财）家庭备用金账户」，金额 ¥12,345,678.90）、动态字体最大档 / 字体 200% 下不截断、不重叠。

## 1. 全局

- **导航**：底部 3 个标签：总览、资产、订阅。每个标签都是大标题导航栏，向上滚动后收起成小标题。导航栏右侧放操作：总览放「设置」（图标与桌面端相同：Lucide sliders / SF slider.horizontal.3）；资产和订阅放「设置」和「＋」，「＋」在最右。
- **页边距 16，卡片间距 12**，卡片内边距 16。卡片、分组列表用桌面端的卡片色与圆角，不加描边。
- **金额**：一律等宽数字。大金额的整数部分用大字号，「.xx」小一级、颜色淡一级。负数用 U+2212「−」加负值色。**任何金额都不得截断**：放不下时整体缩小字号（最小 60%），仍放不下时换成第二行，不能出现省略号。
- **撤销横幅**：删除、调整余额后，底部标签栏上方浮出一张胶囊卡片，内容是「已删除 招商银行…」和「撤销」按钮，底部有一条 3pt 的 6 秒倒计时条。新操作出现时替换旧横幅；下滑可关闭。续费不可撤销（与桌面端一致，核心续费不返回撤销票据），只用同一位置的提示条显示「已顺延 N 期」，不带「撤销」按钮。
- **触感**：保存成功、续费用 success；删除用 warning；切换分段控件用 selection。
- **动效**：金额变化用数字滚动过渡；列表的插入和删除带动画；保存后，被改动的那一行高亮约 1 秒。

## 2. 总览（单列，从上到下）

1. **净资产主卡**
   - 标签「净资产」，下面是主金额，用最大字号。
   - 再下面一行三格指标并排：总资产 ｜ 总负债（负值色）｜ 负债率。
   - 底部一条 4pt 的负债率细条。
   - 点主卡进入「资产」标签。
2. **「接下来」卡**
   - 左侧：标签「本月待扣」、金额；如果有美元，另起一行写「另有 $25.80」。
   - 右上角：一枚「下一笔」胶囊，写「11月20日 · Netflix」，取今天及以后最早的一笔（不含逾期，同桌面端订阅页「下一个扣费」）；名称超长时省略，金额不省略。
   - 中部：扣费时间线，高 56。数据只用核心 `overview.upcoming`（30 天内、含逾期、最多 5 笔，同桌面端总览「即将扣费」），每笔一个标记，不在界面层按天加总金额；逾期的标在「今天」位置，用负值色，其余用强调色。标记下方列出这几笔的日期、名称、金额。
   - 底部：「12 个订阅 · 1 笔待确认 ›」。有待确认时，这一行用负值色浅底，点击跳到订阅标签的「待确认」分组。
3. **资产构成卡**（标题行写「资产构成」，右侧「全部明细 ›」）
   - 左侧：环形图，直径 112，只画资产，不含负债。环中心只放「5 类」或者最大类的占比，**不放金额**，避免和环相撞。
   - 右侧：图例列表，每行是色点、分类名、占比；金额放在第二行，字号小一级。
   - 卡片底部单独一行：「负债 −¥1,301,265.30」，用负值色。
   - 点图例某一行，跳到资产标签里对应的分组。

## 3. 资产

1. **页头**（不做成卡片）：总资产金额，加一行小字「N 项记录 · 5 个固定分类」。
2. **5 个固定分区**，顺序同桌面端，用 inset grouped 样式：
   - 分区头：左边是分类图标块、分类名、数量；右边是分区合计。
   - 每一行：分类图标块；名称（最多 2 行）；副标题「历史 N 条 · 更新于 11月14日」；右边是金额和 ›。
   - 空分区只放一行「＋ 添加流动资金」，用虚线描边，点击打开新建面板，并预选这个分类。
3. **手势**：
   - 左滑：「删除」，可一滑到底直接删。
   - 右滑：「调整余额」。
   - 长按菜单：调整余额、重命名、删除。
   - 点击：进入资产详情。
4. **「＋」新建面板**（底部 sheet，可在半屏和全屏之间拖动，顶部有抓手）：
   - 分类用 5 个图标块网格选择。
   - 名称、金额（数字键盘，人民币；资产不分币种，与桌面端一致）。
   - 导航栏「取消 / 新建资产 / 保存」。必填项未填时「保存」置灰；出错时在对应输入框下面显示负值色文字。

## 4. 资产详情（从资产列表推入）

1. 头部：分类图标块和名称，下面是大金额。
2. 按钮行：「调整余额」主按钮占满宽度；下面放「重命名」次级按钮。
3. 「变动记录」分组列表：
   - 每行：日期和时间；最新一条带「当前」标签；变化量（＋ 正值色 / − 负值色）；余额。
   - 点某一行，弹出「修正这条记录」。
   - 被修正过的行可以展开「修正记录：改前 → 改后」。
   - 分组脚注：「修正不会新增快照」。
4. 页面最底部：文字按钮「删除这项资产」，用负值色。删除后返回列表，显示撤销横幅。

## 5. 订阅

1. **统计**，2×2 卡片网格：本月待扣、月均支出、年化支出、下一个扣费。月均和年化的标签右侧加一个 ⓘ，点开显示计算说明，文案用文案表里的原文。
2. **待确认**分组，只在有待确认时出现，排在最前：
   - 行副标题用负值色写「逾期 N 天」。
   - 行右侧是「✓ 已续费」胶囊按钮。点击后有触感反馈，这一行动画移出，并提示「已顺延 N 期」（无撤销）。
3. **其余分组**与桌面端完全一致：用核心 `subscription_group` 的结果，依次为本月、下月、之后、已暂停，组内按下次扣费日升序；分组全部展开（桌面端不折叠）。
5. **每一行**：图标块（分类色）；名称；副标题「11月20日 · 每月 · 6 天后」；右侧金额，下面一行小字写周期。
6. **手势**：
   - 左滑：删除。
   - 右滑：暂停或恢复。
   - 长按菜单：编辑、暂停/恢复、删除。
   - 点击：打开编辑面板。
7. **编辑面板**（底部 sheet，全屏）：
   - 名称、金额、币种分段、周期分段、下次扣费日（紧凑日期选择）。
   - 说明文字用文案表原文。
   - 「保存」的规则同资产。

## 6. 设置（点齿轮从底部弹出，全屏，面板内可推入下一级）

分组顺序：

1. **外观**：主题分段控件，选项为「跟随系统 / 浅色 / 深色」。
2. **备份**：导出备份、导入备份、导出加密备份、导入加密备份。
3. **同步密钥**：显示密钥指纹（等宽字体，长按可复制），下面是导出恢复码、导入恢复码。
4. **数据**：数据位置；「清空全部数据」（负值色）。
5. 页脚：「离线运行 · 无网络请求」和版本号。

所有覆盖类、不可逆的操作，都弹系统确认框，文案逐字用桌面端原文。

## 7. 空状态

每个标签页各一个，居中排布：

- 64pt 的分类图标组合图形
- 标题
- 一行说明，用桌面端原文
- 主按钮

总览的空状态按钮是「记下第一笔资产」，订阅的是「新建订阅」。

## 8. iPad 与安卓平板（宽度 ≥ 600 或横屏）

**基准是 iPad。** 安卓平板逐页对齐 iPad 的结构、卡片、图表和导航样式，只保留系统层面的原生行为（返回手势、SAF、TalkBack、48dp 触控区）。Mac 窗口同样遵守本节的导航规则。

- **侧边栏**（iPad、Mac、安卓平板一致）：
  - 顶部是应用名「SnowFold」，下面是「总览」「资产与负债」「订阅」，图标在左、文字在右，整行可点。
  - 选中项：iPad 和安卓为品牌蓝实底圆角条，图标和文字为白色；Mac 沿用系统侧边栏的选中样式。
  - **「设置」固定在侧边栏左下角**，只靠中间留白与上面三项分开，**上方不加分隔线**，行样式与选中样式和其他项相同。
  - 安卓平板不用 NavigationRail（图标在上、文字在下），改成与 iPad 同样的侧边栏，宽约 200–240dp。
- **右上角不再放设置按钮**：宽屏下（iPad 常规宽度、Mac、安卓 ≥600dp）设置只从侧边栏左下角进入，所有页面和列表栏工具条里的设置按钮都去掉，页面自己的操作按钮（如「＋」）保留。手机和 iPad 分屏变窄时没有侧边栏，右上角设置按钮照旧。
- **总览**：大标题下面一行日期和「数据已保存在本机」。第一行是净资产主卡和「本月待扣」卡（下一笔扣费放在卡片右上角，下面是「N 个订阅 · M 笔待确认 ›」）。第二行在卡片外放分区标题：「资产构成」配「全部明细」，「30 天扣费安排」；构成卡左边环形图，右边带分隔线的图例，底部单列负债；扣费卡是柱状图，柱高表示当天笔数，逾期为红色，下面一行说明。第三行是全宽的「即将扣费」列表（日期、名称、状态标签、金额），右上配「全部订阅」。
- **资产**：中间一栏放列表，右侧放详情，详情内容同第 4 节。
- **订阅**：中间一栏放列表，右侧栏直接嵌入编辑表单，不再弹出面板。
- **设置**：在右侧详情栏里显示，不弹出面板。
- 禁止把手机的单列布局直接拉宽。
