# 使用说明

数据目录、快捷键、备份、换机与恢复的操作说明。四端功能一致（GPUI 桌面、iPhone/iPad/Mac SwiftUI、安卓 Compose），都由同一个内核提供；快捷键只在桌面端有。

功能概览：资产页支持五个固定分类、新建、名称与余额行内编辑、余额快照、历史修正、删除及 6 秒撤销；总览从当前数据计算总资产、负债、净资产、分类占比与待扣订阅；订阅支持 CNY/USD、周/月/季/年周期、日期选择、逾期多期续费、暂停/恢复、删除撤销，以及分组与分币种统计；设置提供主题、JSON 导入导出、覆盖确认、清空，以及加密备份与同步密钥恢复码。

## 数据目录

数据只存本机 SQLite，运行时不联网。设置中显示实际路径。

| 宿主 | 数据目录 |
| --- | --- |
| GPUI 桌面（Windows） | `%LOCALAPPDATA%\SnowFold\data\`（`snowfold.sqlite3`） |
| SwiftUI（Mac） | `~/Library/Containers/app.snowfold/Data/Library/Application Support/SnowFold/` |
| SwiftUI（iPhone/iPad） | 应用沙盒 `Application Support/SnowFold/` |
| Compose（安卓） | 应用私有 `filesDir` |

GPUI 桌面端可用环境变量 `SNOWFOLD_DATA_DIR` 指定独立目录（例如验收时与正常数据分开）；升级时保留数据目录。不要让多个实例同时编辑同一个数据库。

## 启动备份

各端每次启动都在数据目录 `backups/` 下保存一份明文 JSON 备份，最多保留 10 份，用于误删恢复。该备份是明文，**不要把数据目录放进 iCloud/OneDrive 等云盘同步**；需要上云请使用加密备份。

## 快捷键（GPUI 桌面端）

| 操作 | 快捷键 |
| --- | --- |
| 总览 / 资产 / 订阅 | Cmd/Ctrl+1 / 2 / 3 |
| 当前页面新建 | Cmd/Ctrl+N |
| 设置 | Cmd/Ctrl+, |
| 输入确认 | Enter |
| 关闭编辑、浮层与设置 | Esc |
| 控件导航 / 激活 | Tab、Shift+Tab / Enter、Space |

窗口初始内容尺寸 1440×900，最小 960×720，保留系统标题栏。

## JSON 导入导出

- 导出：设置里「导出备份」保存为 JSON 文件，可随时导入恢复。
- 导入：先验证全量数据，再弹窗确认覆盖；确认后在 SQLite 事务里整体替换。非法输入或事务失败不会部分替换当前数据。导入会覆盖当前所有记录，请先导出备份。
- 备份格式带 `format_version` 并按版本解码；记录身份为 UUID，修正保留原值，删除只留墓碑；主题是独立的本机设置。格式细节见 [core-api.md](core-api.md)。

## 加密备份与换机

- 「导出密文」生成 `.sfseal` 加密备份：AES-256-GCM 密封包，可安全上传网盘或发给他人，服务器只能看到密文。信封与密钥细节见 [SECURITY.md](../SECURITY.md)。
- 同步密钥保存在数据目录的 `snowfold-sync.key`；设置页显示密钥指纹，便于核对两台设备。
- **换机或重装**：先在本机设置里「导出恢复码」，到新设备「导入恢复码」，再导入加密备份。**恢复码丢失后加密备份无法恢复**，请离线保存，不要放云盘同步目录。
- 加密备份内部带有导出时间与设备标识；导入确认页会显示，方便识别「云端把新备份换成了旧备份」。程序不做密码学防回滚（需要服务端单调计数），以确认页信息为准，可疑时取消并从自己的设备重新导出。
- 导入加密备份会先认证解密并全量校验，再要求确认，最后在 SQLite 事务里整体替换；密钥错误、篡改或事务失败都不会改动现有数据。

## 恢复码

- 恢复码是主密钥的明文文件，导出时以 0600 权限写入；内容包含密钥指纹与使用说明。
- 导入恢复码会先显示当前指纹与新指纹对照并要求确认；确认后写入新密钥，旧密钥保留为 `snowfold-sync.key.bak`，旧密钥导出的备份需要用该备份恢复。

## 清空

「清空全部数据」会删除本机全部资产、历史与订阅，不能撤销；确认弹层会再次要求确认并建议先导出备份。
