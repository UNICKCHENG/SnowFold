# SnowFold 移动端布局（iPhone/iPad 定稿，安卓手机/平板照做）

状态：**冻结**（2026-11 界面重做定稿）。视觉语言（颜色、字号、图标、组件）见 [design.md](design.md)，本文只定移动端的布局与交互。设计稿：`iphone/*.png`（393×852 主，375×667 最窄）、`ipad/*.png`（1180×820），深浅色各一套。

安卓与 iPhone 结构、尺寸、控件外观完全一致（dp 等于 pt）。安卓只保留：系统状态栏与导航条、返回手势、系统文件选择框（SAF）、TalkBack、跟随系统字号；不用 Material 的底部导航、对话框、水波纹、悬浮按钮、开关。安卓平板照 iPad。

## 1. 全局（iPhone）

- 页边距 16；卡片圆角 16；分区间距 28（总览）/ 24（其余）；分组头在卡片外。
- **导航栏**：状态栏下高 52，标题居中（分区标题级，**不用大标题**，保证每屏焦点是金额）；右侧 44 圆形浮层按钮：总览＝同步按钮（开启同步时），资产＝「＋」添加资产，订阅＝「＋」新建订阅，设置＝无。推入的详情页左侧为返回按钮（chevron-left）。
- **标签栏**：悬浮胶囊，浮层材质，左右各 24，下距 28（375×667 机型 12），高 64，内边距 4。四项等宽：总览、资产、订阅、设置；每项图标 24 + 文字（辅助级）；选中项 56 高胶囊 brand-soft 底 + 实心图标 + brand 中等文字。iOS 26 用系统 `TabView`（Liquid Glass），全局 tint 设 brand；安卓用 Haze 自绘同形。
- 内容底部留出标签栏高度 + 56（120），最后一张卡片不被遮挡。
- 动态字体 / 系统字号最大档：行内左右排列改上下排列；金额整体缩小不低于 60%，不截断。
- 触控：所有可点元素命中区 ≥44pt / 48dp（视觉更小的按钮用透明内边距补足）。

## 2. 总览

1. 净资产：标签（正文中等 text2）→ 金额（大标题，唯一最大字号）→ 下距 16 三项（总资产、总负债 neg、负债率；标签辅助 text2、值正文中等；间距 20，放不下自动换行）。
2. 「资产构成」分区头（+「全部明细 ›」辅助中等 brand）→ 卡片：8 高构成条 + 五行（图标块 32、分类名正文中等 + `{n} 项` 辅助 text2；右侧金额正文中等 + 占比辅助 text2）。点行跳到资产页对应分类。
3. 「即将扣费」分区头（+「全部订阅 ›」）→ 卡片：最多 5 行（名称正文 + 日期辅助 text2；徽标；金额）+ 订阅摘要行（同桌面）。为空时卡片内「未来 30 天没有扣费」空状态。
4. 无资产时整页为总览空状态（标签栏保留）。

## 3. 资产

1. 汇总（不做卡片）：「总资产」+ 金额（页标题级，本页焦点）→ 下距 8：总负债（neg）、净资产（标签辅助 + 值正文中等，间距 20）。
2. 五个分类分区（间距 24）：分区头（图标块 28、分类名分区标题、`{n} 项`、右侧合计）→ 卡片，每行：名称（正文，可多行）+ 金额 + chevron-right 16。空分类为紧凑空状态行。
3. 点行推入**资产详情**：分类（图标块 24 + 辅助）→ 名称（分区标题）→ 余额（页标题级）→ `更新于 {date} · 历史 {count} 条` → 按钮行「调整余额」（主要）「重命名」（次要）+ 右端「删除」（文字 neg）→「变动记录」卡片（同桌面，行内「修正」命中区 44）。删除后返回列表，出撤销横幅。
4. 手势：左滑行露出「删除」（neg，可一滑到底）；长按菜单：调整余额、重命名、删除。
5. 无资产时整页为资产空状态。

## 4. 订阅

1. 汇总：「本月待扣」+ 金额（页标题级）+ 美元行（`+ $xx` 正文 text2）→ 下距 16 两列：月均支出、年化支出（标签辅助 + info 16，点开显示口径说明；值分区标题级；美元辅助）→ `{active} 个在订 · {paused} 个已暂停`（辅助 text2）。
2. 分组同桌面（待确认组头 neg）。行（最小高 64）：头像 36、名称（正文，可多行）+ 副标题（待确认：`逾期 {n} 天 · ` 开头 neg；其余 `{周期} · {日期}` text2；各段不在中间断行）、右侧金额（正文中等）；待确认行金额下方「已续费」浅色按钮（高 32，命中区 44）。
3. 手势：左滑露出「已续费」（brand 底，仅到期行）与「删除」（neg 底），各宽 88，图标 20 + 辅助中等文字；长按菜单：编辑、暂停/恢复、删除。点行打开编辑 sheet。
4. 续费：触感 success，行动画移出，通知「已顺延 {n} 期」。删除：触感 warning，撤销横幅。

## 5. 设置（第四个标签）

分组卡片（行：标题正文 + 说明辅助 text2，可点行右侧 chevron-right）：

1. 外观：主题（行内满宽分段 自动/浅色/深色）。
2. 数据：导出备份、导入备份、清空全部数据（标题 neg，无 chevron）。
3. 加密备份：加密备份、恢复加密备份、同步密钥指纹（右侧等宽 text2，长按复制）、同步密钥恢复码（说明行），导出恢复码、导入恢复码。
4. 同步：**未配置**＝表单行（标签宽 112 + 输入）、使用路径风格地址开关，组下 `sync_help`，下方「保存配置」主要按钮满宽；**已配置**＝开启同步（开关 + 「上次同步 {time}」）、存储（说明为地址，点击推入同一表单修改）、「立即同步」文字按钮；同步策略组（同桌面）；最下「清除配置」文字 neg。
5. 关于：`app_version` + `offline_description`。

覆盖类、不可逆操作弹确认框（design.md §5.6 移动确认框）。

## 6. Sheet（添加资产、调整余额、修正历史、新建/编辑订阅）

- iPhone：从底部弹出到状态栏下（顶部 y=62），顶部两角圆角 28，底色 bg；顶部 5 高、36 宽抓手（sep 色），可下拉关闭（等于「取消」）。
- 头部：左「取消」44 圆形浮层按钮（close 图标，读屏「取消」），中间标题（分区标题级），右「保存」44 圆形按钮（brand 底 + check 图标，读屏「保存」；必填未填时 sep 底 + text2 图标、不可点）。iOS 26 用系统 sheet 工具栏按钮的同一形态。
- 表单：一张卡片，行（最小高 52）：标签（正文，宽 96）+ 值/输入；分段控件独占一行（标签在上，控件满宽）。卡片下方：错误行（warning-triangle 16 + 辅助 neg）、说明（辅助 text2）。编辑订阅时再下方一张卡片：「暂停/恢复」（brand）、「删除订阅」（neg）。
- iPad：居中表单 sheet，宽 540，**高度随内容**（最小 320，超过窗口高 85% 时内部滚动），垂直位置略高于中心（中心线在 46%），圆角 28，无抓手。不用固定 640 高，避免字段少时下方大片空白。
- 键盘：金额字段用数字小数键盘；名称字段回车跳下一字段；最后一个字段回车等于保存。

## 7. 撤销横幅与通知

标签栏上方，左右 16，下距 112，胶囊（圆角 26，最小高 52，长文案换行）。其余同 design.md §5.8。可下滑关闭。

## 8. iPad（安卓平板照做）

- 侧边栏：浮层材质，距边 8，宽 260，圆角 24；顶部「SnowFold」（分区标题级）；项目行高 44、图标 24、左右 12；设置在左下角；选中同桌面。
- 工具栏：状态栏下，高 56，左距 24：页面标题（分区标题级）；右侧 44 圆形按钮（同步、＋）。
- 页面布局对齐桌面形态（design.md §9.2–9.4）：总览两列；资产两栏（左列 380，右栏概览/详情）；订阅单列宽行。字号与控件尺寸用移动档。
- 设置：内容区单列，最宽 720 居中，分组同 iPhone。
- 弹层：表单 sheet（§6）；确认框同 iPhone。
- 分屏变窄（<600）时退回 iPhone 布局（标签栏）。

## 9. 错误

- 启动失败：整页错误空状态（同桌面 §9.7），不显示标签栏。
- 密钥不可用：总览顶部 warn-soft 卡片，按钮「导入恢复码」。
